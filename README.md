# 宏國地政 LINE 會員與付費諮詢入口

此專案提供 GitHub Pages 公開前端，預定網址：

`https://homegoestate.github.io/line-member-booking/`

## 第一階段功能

- LINE 內嵌手機版介面
- 選擇服務
- 選擇楊總或不指定顧問
- 選擇候選日期與時間
- 清楚標示「送出申請不代表預約成立」
- 匯款及人工核帳後才正式寫入 Google 行事曆

## 安全邊界

GitHub Pages 只放前端畫面。LINE 密鑰、Google Calendar 權限、會員資料、簡訊驗證及正式入曆必須由安全後端處理，不得寫入此公開儲存庫。
